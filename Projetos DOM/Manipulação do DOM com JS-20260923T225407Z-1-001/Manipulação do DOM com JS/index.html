Exemplo 01 - Manipulação de texto usando o innerText

O innerTExt é usado para manipulações de textos dentro de tags HTML, como por exemplo H1, H2, H3, P etc. Podemos utilizar para isso também o innerHTML.

O innerHTML permite criarmos códigos HTML dentro de tags já existentes, por exemplo, adicionar um botão dentro de uma div.
